# Voice AI Assistant 🎙️

مساعد صوتي عربي يعمل من المتصفح باستخدام OpenAI.

## الجديد في الإصدار 1.1

- 🧠 محادثة متعددة الأدوار مع حفظ سياق آخر الرسائل.
- 💾 حفظ المحادثة محليًا في المتصفح.
- 🎙️ تسجيل صوتي مع إظهار النص أثناء الكلام.
- 🔊 قراءة الإجابة بصوت عربي مع زر لإيقاف الصوت.
- 🌙☀️ وضع داكن وفاتح مع حفظ الاختيار.
- ⚡ أزرار أسئلة سريعة.
- 📱 تصميم متجاوب للموبايل والكمبيوتر.
- 🛡️ التحقق من طول المدخلات وتنظيف سجل المحادثة على الخادم.

## التشغيل

```bash
npm install
OPENAI_API_KEY=your_key npm start
```

ثم افتح `http://localhost:3000`.

### المتغيرات

- `OPENAI_API_KEY`: مفتاح OpenAI المطلوب للردود.
- `OPENAI_MODEL`: اختياري، والافتراضي `gpt-5-mini`.
- `PORT`: اختياري، والافتراضي `3000`.

> لا تضع مفتاح API داخل ملفات الواجهة أو GitHub. استخدم متغيرات البيئة أو Secrets.

## الاختبار

```bash
npm test
```

الاختبار يتحقق من صحة JavaScript في الخادم والواجهة. التعرف على الكلام يعتمد على Web Speech API، والنطق على Speech Synthesis في المتصفح.
