# Production Object Storage Adapter

EduAI keeps uploaded documents outside the application container. The storage boundary requires a private object-storage adapter.

`src/infrastructure/object-storage-s3.js` provides an S3-compatible adapter with an injected client, so AWS, Cloudflare R2, MinIO, Backblaze B2, or another compatible provider can be selected without coupling the application core to a vendor SDK.

## Required production controls

- Private bucket/container only.
- Tenant-scoped object keys generated by `buildTenantObjectKey`.
- Server-side encryption enabled by the target provider.
- Short-lived signed URLs for reads/downloads.
- Credentials supplied by the deployment secret manager, never committed to Git.
- Network access restricted to the application/worker identity where supported.
- Lifecycle and deletion policies configured for the organization's retention requirements.

The adapter intentionally accepts an injected S3-compatible client. Provider-specific SDK construction belongs in deployment wiring, where credentials and endpoints can be supplied securely.
